# Releasing

How the package is versioned, tagged, and published.

## Overview

`laravel-config-webhook` is published on [Packagist](https://packagist.org/packages/cleaniquecoders/laravel-config-webhook).
Releases are cut from `main` with a semver tag; the changelog is generated automatically.
